# Framework skills

DevOps works *on* DUDES, outside the role-play (`CORE.md` §5, world **framework**). Every skill here:

- is named for its task and lives here, in `skills/framework/` — the folder is what makes it a framework skill;
- runs on request only: never always-on, never in `recipes/<phase>.json`, and the engine refuses it for a worker;
- leaves framework files alone during its run — a result lands through `maintain`, when the human asks.

Which one to load, and when: workspace `AGENTS.md` §DevOps skills.
