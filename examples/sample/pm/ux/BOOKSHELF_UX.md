# BOOKSHELF UX

## 1. Users and context

A reader on a phone, often one-handed, in changing light. German UI; informal address.

## 2. Tokens

| Token | Value |
|---|---|
| Surface | `#FAF7F2` |
| Text | `#1F1B16` |
| Accent | `#2F6F5E` |
| Border | `#D8D2C8` |
| Touch target | at least 48 px |
| Type | system sans-serif, 18 px body |

## 5. Microcopy

| ID | Kontext | Text |
|---|---|---|
| W-MC-01 | Button, add | „Buch hinzufügen“ |
| W-MC-02 | Toast, after adding | „Zum Regal hinzugefügt“ |
| W-MC-03 | Field error, title | „Der Titel fehlt oder ist zu lang.“ |
| W-MC-04 | Button, mark read | „Als gelesen markieren“ |
| W-MC-05 | Empty shelf | „Dein Regal ist noch leer. Füge das erste Buch hinzu.“ |

## 11. Screens

### UXB-01 · Shelf

- **UXB-01.1** *List* — the books in the order they were added, each with title, author and a read mark; the button W-MC-04 sits on an unread book; the empty shelf shows W-MC-05.
- **UXB-01.2** *Form* — two fields, title and author, and the button W-MC-01; a refused title shows W-MC-03 under the field; a saved book shows the toast W-MC-02.
